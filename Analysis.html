MDPT Analysis

Welcome to the Multiple Disease Prediction Tool (MDPT) Analysis page!
This dashboard provides a comprehensive visual analysis of the MDPT project. It highlights key insights from the dataset, model performance, and overall system behavior.
Here’s what you’ll find in the analysis:
📊 Prediction Summary:
Overview of disease predictions across multiple categories based on patient input.
🔎 Patient Profile Breakdown:
Detailed analysis of age groups, gender distribution, and symptom patterns.
🧠 Model Performance Metrics:
Accuracy, precision, recall, and F1-score of different machine learning models used in MDPT.
⚙️ System Insights:
How input features like symptoms, habits, and clinical parameters influence prediction outcomes.
🩺 Disease Trends:
Visualization of most frequently predicted diseases and associated risk factors.
🌐 Interactive Reports:
Clickable, filterable dashboards to explore how different variables impact disease prediction.
